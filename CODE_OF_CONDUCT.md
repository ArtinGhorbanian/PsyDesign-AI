# Code of Conduct

## Our working standard

This private project should be a place for careful, respectful collaboration.
Participation requires professional communication, good-faith technical
debate, and respect for privacy, accessibility, cultural differences, and the
unresolved rights of every contributor and stakeholder.

Positive conduct includes:

- discussing ideas and evidence rather than attacking people;
- giving specific, constructive feedback;
- making room for different experience levels and communication styles;
- correcting mistakes without humiliation;
- respecting boundaries and keeping private material private; and
- documenting decisions, provenance, and uncertainty honestly.

Unacceptable conduct includes harassment, threats, discriminatory language,
sexualized attention, stalking, doxxing, retaliation, deliberate disruption,
or publishing private repository content. Misrepresenting authority,
ownership, endorsement, release approval, or another person's work is also
unacceptable.

## Scope

This code applies in issues, Discussions, pull requests, reviews, commits, and
other project spaces. It also applies when someone represents the project in a
way that could reasonably affect its participants. It does not authorize any
public representation of this private project.

## Raising a concern

Open an issue in this private repository with a title beginning `Conduct:` and
include only the information needed to understand the concern. For a general
policy question, use GitHub Discussions when enabled.

Issues and Discussions are visible to their repository audiences. The project
does not currently provide a confidential external reporting channel, so do
not include unnecessary personal or highly sensitive information.

## Response

Repository administrators may clarify expectations, request corrective action,
limit participation, remove content, or revoke repository access in proportion
to the conduct and available evidence. Reports should be handled consistently,
with attention to safety, privacy, conflicts of interest, and an opportunity
for affected participants to provide relevant context where appropriate.

No response under this code decides intellectual-property ownership or grants
permission to publish the project.
