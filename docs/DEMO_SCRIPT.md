# PsyDesign AI Demo Script

## Purpose

This script demonstrates the verified local product in deterministic demo mode. It requires no AI key, makes no external provider call, and should take about four minutes at a conversational pace.

## Before recording

1. Install the pinned development dependencies.
2. Confirm `PSYDESIGN_MODE` is unset or set to `demo`.
3. Start `python app.py` and open `http://127.0.0.1:8000`.
4. Confirm the visible badge says **Demo mode**.
5. Remove any unrelated local history so only synthetic demo text appears.
6. Use a clean browser profile or crop browser chrome so no private tabs, bookmarks, paths, or accounts appear.

## Four-minute walkthrough

### 0:00–0:30 — Product premise

Show the desktop workspace and say:

> PsyDesign AI turns one focused brand brief into a structured psychology, audience, identity, narrative, and campaign direction. This demo runs entirely through a deterministic local provider.

Point out the language selector, history, mode badge, and data-use disclosure.

### 0:30–1:10 — Create the brief

Use the synthetic example:

> A calm refillable coffee system for busy city creatives who value ritual, clarity, and low-waste choices.

Show the character counter and examples, then choose **Build brand direction**. Mention that the control disables while work is in progress and that the final report receives focus for keyboard and screen-reader orientation.

### 1:10–2:25 — Review the report

Walk through:

- archetype, tone, and values;
- audience persona and pain points;
- controlled local logo plus font direction;
- story, social bio, names, and slogans;
- campaign direction and logo rationale.

Describe every output as an ideation draft. Do not imply trademark, originality, factual, or legal clearance.

### 2:25–3:10 — Test the persona

Ask:

> How should this brand welcome a first-time customer?

Show the reply, copy control, and read-aloud control. Explain that demo speech is local generated audio and that provider mode is an explicit server configuration.

### 3:10–3:40 — History and privacy boundary

Reopen the saved report from history, download the logo, then demonstrate deletion. Explain that signed browser sessions separate history in the current local workflow but are not user authentication.

### 3:40–4:00 — Responsive and multilingual finish

Switch to the 375 px layout, open and close the navigation with Escape, and show Arabic to demonstrate RTL direction. Close with the main limitations: private rights-pending release, local single-instance storage, and unverified live provider integration.

## Suggested recording shots

1. Desktop first impression.
2. Brief submission and loading state.
3. Report masthead and the first two strategic cards.
4. Visual-identity and campaign sections.
5. Persona reply and speech control.
6. Mobile report and RTL view.
7. Final architecture diagram or concise limitation card.

## Claims to avoid

Do not call the build production-ready, enterprise-grade, legally cleared, trademark-safe, fully secure, or live on the public internet. Do not show a real key, `.env`, local path, database, personal account, or generated record from another user.
